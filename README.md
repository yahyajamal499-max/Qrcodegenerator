# QR Code Scanner

A responsive and user-friendly **QR Code Scanner** built with **HTML, CSS, and JavaScript**.

The application can scan and detect different types of QR code content, including text, URLs, phone numbers, email addresses, Wi-Fi credentials, and images.

## 🚀 Features

* 📷 Scan QR codes using your device camera
* 🖼️ Scan QR codes from uploaded images
* 🔗 Detect and open URLs
* 📧 Detect email addresses
* 📱 Detect phone numbers
* 📝 Read and display text
* 📶 Detect Wi-Fi QR codes
* 🖼️ Support QR codes containing image-related information
* ⚡ Fast QR code detection
* 📱 Responsive design for desktop and mobile devices
* 🎨 Simple and user-friendly interface

## 📋 Supported QR Code Types

## 💻 How to Run

### Option 1: Run Locally

1. Clone the repository:

```bash
git clone https://github.com/yahyajamal499-max/Qrcodegenerator.git
```

2. Open the project folder:

```bash
cd Qrcodegenerator
```

3. Open `index.html` in your browser.

### Option 2: VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Use **Live Server** to launch the application.
4. Allow camera permission when prompted.

## 📷 Camera Permission

When using the camera scanner, your browser may ask for permission to access the camera.

Select **Allow** to enable QR code scanning.

For a deployed website, camera access generally requires a secure **HTTPS** connection.
